휴대폰 홈 화면에 바로가기 만들기

이 HTML 파일 자체로도 학습할 수 있지만, 앱처럼 홈 화면에 설치하려면 이 PWA 폴더를 GitHub Pages·Cloudflare Pages·Netlify 같은 HTTPS 호스팅에 올린 뒤 그 주소를 휴대폰 브라우저에서 여는 방식이 가장 안정적입니다.

아이폰 / 아이패드

  1. 사이트 주소를 Safari에서 엽니다.
  2. 하단 또는 상단의 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 선택합니다.
  4. 이름을 확인하고 추가를 누릅니다.

안드로이드 / Chrome

  1. 사이트 주소를 Chrome에서 엽니다.
  2. 오른쪽 위 ⋮ 메뉴를 누릅니다.
  3. 홈 화면에 추가 또는 앱 설치를 누릅니다.
  4. 설치를 확인합니다.

사이트를 올리는 가장 간단한 방법

  1. 함께 제공된 PWA ZIP의 압축을 풉니다.
  2. GitHub Pages, Cloudflare Pages, Netlify 중 하나에 폴더 전체를 업로드합니다.
  3. 생성된 HTTPS 주소를 휴대폰에서 열고 위 단계대로 홈 화면에 추가합니다.
참고: 단순 다운로드한 로컬 HTML(file://)은 iOS/Android에서 홈 화면 설치와 음성 기능 동작이 브라우저별로 제한될 수 있습니다.
